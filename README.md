## 🇧🇩 BanglaBhasha Compiler

> **A custom Bengali programming language compiler built from scratch in Python.**

BanglaBhasha allows source code to be written using **Bangla keywords and Unicode identifiers**, while following the classical stages of compiler construction.

### ⚙️ Compiler Pipeline

```text
BanglaBhasha Source Code
          │
          ▼
        Lexer
          │
          ▼
        Tokens
          │
          ▼
        Parser
          │
          ▼
          AST
          │
          ▼
 Semantic Analysis
          │
          ▼
    Symbol Table
          │
          ▼
      TAC / IR
          │
          ▼
 Python Code Generator
          │
          ▼
      Execution
```

### ✨ Highlights

* 🇧🇩 Bangla-based programming syntax
* 🔍 Lexical analysis
* 🌳 Abstract Syntax Tree
* 🧠 Semantic analysis
* 🏷️ Symbol-table management
* ✅ Static type checking
* ⚙️ Three-Address Code generation
* 🐍 Python code generation
* 🧩 Functions
* 🏛️ Classes & Objects
* 📚 Stack & Queue
* 🌐 Interactive Web Compiler
* 🌳 Visual AST inspection
* 📋 Symbol-table viewer
* ⚙️ TAC viewer
