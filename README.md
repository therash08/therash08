## 🔥 Featured Projects

### 🇧🇩 BanglaBhasha Compiler

A custom Bengali programming language compiler developed in Python.

The project follows a complete compiler pipeline:

```text
BanglaBhasha Source
        ↓
      Lexer
        ↓
      Parser
        ↓
       AST
        ↓
Semantic Analysis
        ↓
  Symbol Table
        ↓
     TAC / IR
        ↓
Python Code Generation
        ↓
    Execution
```

**Key Features**

* Bengali programming syntax
* Unicode identifiers
* Lexical analysis
* Recursive-descent parsing
* Abstract Syntax Tree
* Semantic and type checking
* Three-Address Code generation
* Python code generation
* Functions
* Classes and objects
* Stack and Queue
* Interactive browser-based compiler playground

🔗 [View Repository](https://github.com/therash08/BanglaBhasha-Compiler)
