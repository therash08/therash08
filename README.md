## AI/ML Internship Journey

During my **AI/ML Engineering Internship at Crack404**, I have been working through practical, end-to-end projects:

| Week | Project | What I Worked On |
|:---:|:---|:---|
| **01** | [Customer Churn Prediction](https://github.com/therash08/AI_ML_Intern/tree/main/week_1) | EDA, feature engineering, Random Forest tuning, threshold optimization, model evaluation |
| **02** | [Model Serialization & Inference](https://github.com/therash08/AI_ML_Intern/tree/main/week_2) | Pickle, Joblib, standalone `predict.py`, dependency management |
| **03** | [Receipt Digitization with OCR](https://github.com/therash08/AI_ML_Intern/tree/main/week_3) | OpenCV preprocessing, EasyOCR, bounding boxes, confidence analysis, JSON extraction |

**Selected learning outcomes:**

- **Week 1:** Achieved **90.64% recall** on a held-out churn test set, with a precision-recall trade-off.
- **Week 2:** Verified that Pickle and Joblib artifacts of the same trained model produced matching predictions.
- **Week 3:** Processed **5 real receipt images**; detected **329 raw-image** and **317 cleaned-image** OCR text regions. Found that preprocessing did not always improve OCR confidence.

> These are project-specific observations, not claims of production-grade performance. OCR confidence and the number of text detections do not measure recognition accuracy.
